# This project moved

**Arca is now [Sheaf](https://github.com/sheafhq/sheaf).**

Active development, releases, and issues are at:

- Repo: https://github.com/sheafhq/sheaf
- npm: [`@sheafhq/mcp-recorder`](https://www.npmjs.com/package/@sheafhq/mcp-recorder) · [`@sheafhq/verify`](https://www.npmjs.com/package/@sheafhq/verify)
- Live recorder: https://sheaf-recorder.goldencalf.workers.dev

Wire-format constants (`v: "arca/1"` envelopes, the `0x41524341` anchor-tx magic bytes) are intentionally frozen for backwards-compat with receipts already on-chain and verifiers already in the wild.

This repository is archived.
